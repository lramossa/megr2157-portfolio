# A1 – Build Your Professional Portfolio

Task 1-Analysis- 
---
Portfolio 1- https://www.alexandre-allonas.fr/
Upon opening this portfolio, the first thing I noticed was the tabs on the upper top of the website. This made it easy for me to find the projects section. The layout of the portfolio makes it easy to locate what you need in under 60 seconds. Aside from the overview and a few basic description of tools used, there is not a lot of detail pertaining to the projects. We are only given a small picture of the final design/project and we are not show how the engineer made decisions throughout the project. Although this portfolio lacks in depth information regarding decision making, the website is built in a professional tone. 

Portfolio 2- https://natekarau61.github.io/Engineering-Portfolio/#home
Similar to the first portfolio, there are tabs on the side of the website that allow the user to easily find the projects tab. This portfolio is organized and has a clear color palette.  Each project comes with a 3D model, drawings, and pictures. While this is helpful to the reader, it is not enough for someone else to reproduce the work. This portfolio only shows the final results. We are not given any explanation regarding decisions and procedures. This portfolio is created using professional tone.
